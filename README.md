# Cerrajero Leganés

Web estática para GitHub Pages. Subir **el contenido** del ZIP a la raíz del repositorio `cerrajeroeurokey/cerrajero-leganes` y configurar Settings > Pages > Deploy from a branch > main > /(root).

Revisar servicios, cobertura, horarios y datos legales antes de publicar. Las marcas no indican relación oficial.
